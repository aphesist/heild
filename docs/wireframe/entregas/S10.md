# S10 · App do cliente (branch `wf-s10-app-cliente`) · 14/11/2026

App do cliente (subplano 06) completo no wireframe: web instalável, incluído por padrão, com a marca do escritório (todos os temas, claro e escuro), pensado primeiro para o celular (390 px, sem moldura no celular de verdade) e funcionando no computador (botão "Computador" na moldura, com menu lateral). Tudo grava nos dados do escritório, nos dois modos (local e Supabase), sem migração nova. As APIs pagas ou impossíveis são simuladas e marcadas com o selo "demonstração"; o que sai ao cliente nasce agentificado e passa por cartão de aprovação no escritório.

## O que ficou de fora e por quê

- **App na loja e marca branca completa** (manifesto por escritório, ícone, domínio próprio): são complementos e dependem do Tema (S09); o app usa os tokens do tema e um domínio derivado da razão social.
- **Push e PWA de verdade** (service worker, offline): simulados; o wireframe não registra service worker.
- **Aprovação de pagamento pelo WhatsApp com código (S08-A50)**: é da S08 (C10).
- **Pendências de implantação como tarefas**: a faixa de implantação lê a lista fixa da trilha; as tarefas da trilha são da S04.
- **Segundo fator do sócio**: o campo existe no estado de acesso, mas o escritório de exemplo não exige.
- `app-cliente.cjs` e `servicos-app.cjs` antigos falham onde o comportamento mudou de propósito (ver `DECISOES.md`, S10).

## Como testar

```bash
cd app
npm install
npm run typecheck && npm run build
npx vite --port 6100                                   # em outro terminal
node scripts/s10-app-cliente.cjs /tmp                  # 41 verificações, capturas s10-*.png
node scripts/fundacao-fumaca.cjs /tmp                  # continua passando
```

Na mão: `npm run app`, abra `#/app`, toque em João Batista › Receber código › Entrar. Envie o extrato com o arquivo de setembro (devolvido) e depois o de outubro; abra um pedido de simulado de rescisão; em "Ver no painel do escritório", entre como Fernanda Lima e aprove o cartão no chat do DP; volte ao app e responda "vai seguir?". No painel lateral: farol de abertura, simulações e o botão Computador. No celular de verdade (ou largura < 640 px), o app ocupa a tela toda.
